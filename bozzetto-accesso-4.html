Hai dimenticato la password?

Lockit è un sistema «zero-knowledge»: significa che la tua password la conosci soltanto tu. Non è registrata da nessuna parte: né da noi, né da Google, né dentro Chrome; la protezione avviene tutta sul tuo computer, senza alcun account. È proprio questo il motivo per cui nessun estraneo può leggere i tuoi file.

Per la stessa ragione, nessuno può recuperarla. Non esiste un modulo, un'assistenza o un trucco: i file protetti si aprono solo con la password esatta.

Nemmeno il file di soccorso serve in questo caso: apre i file senza bisogno del sito, ma sempre con la password.

Cosa puoi fare: prova con calma le varianti che usi di solito (maiuscole, numeri in fondo, vecchie abitudini). Se hai copie dei file fatte quando erano ancora leggibili (un backup, una chiavetta), quelle funzionano normalmente.
