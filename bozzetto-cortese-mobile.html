LOCKIT

Lockit funziona dal computer

Per custodire una cassaforte servono permessi sulle cartelle che i telefoni, per ora, non concedono alle pagine web. Usa Lockit da un computer, con Chrome o Edge: ritroverai qui la tua cassaforte quando i telefoni saranno pronti.

Se dal telefono ti serve aprire un singolo file protetto, puoi farlo col file di soccorso, sempre con la tua password.
